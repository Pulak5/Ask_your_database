# Training Data

Training data is generated by running:
```bash
python -m src.training.prepare_data --output-dir data/train --eval-file data/eval/demo_eval.jsonl
```

## Sources
1. **Spider dataset** (train split) — converted to PostgreSQL-compatible SQL and the app's standard prompt format.
   - License: CC BY-SA 4.0
2. **Synthetic in-domain data** — generated specifically for the Pagila DVD-rental database schema, validated to execute without error on PostgreSQL.

## Leakage Guard
The preparation script (`src/training/prepare_data.py`) runs an automated check comparing candidate training questions against the held-out test set in `data/eval/demo_eval.jsonl`:
- Exact string matches are discarded immediately.
- Fuzzy matches with `difflib.SequenceMatcher.ratio() > 0.8` are filtered out.
- Any unresolved duplicate triggers an explicit process termination.

## Datasets Produced
- `data/train/train.jsonl` — Training examples in SFT format:
  `{"prompt": "### Schema:\n...\n\n### Question:\n...\n\n### SQL:\n", "completion": "SELECT ..."}`
- `data/train/val.jsonl` — Validation set (10% split) for evaluation and early stopping during LoRA fine-tuning.
